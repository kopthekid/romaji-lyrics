Connect to Last.fm

The app finds out what you're playing on Spotify through Last.fm. It's free and works with Spotify Free.

  1. Make a free account at last.fm/join.
  2. In Last.fm Settings → Applications, connect Spotify.
  3. Create an API account at last.fm/api/account/create (any app name works, leave the callback URL empty) and copy the API key.

Saved only on this phone.
